## Tips for Good Screenshots
1. Make sure BOTH the SQL query AND the Result grid are visible
2. Use Ctrl+Plus in Workbench to zoom in if text is small
3. Capture the full query tab, not just a partial window
4. For each screenshot, save as: Tables_customers.png, Queries_insert_customer.png, etc.
